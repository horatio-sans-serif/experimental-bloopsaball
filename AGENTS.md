# AGENTS.md — bloopsaball

Started 2026-10-18. Product concept plus a browser simulator; no hardware built yet. Read
`README.md` first.

## Commands

- `npm test` — 21 hermetic node tests (`test/core.test.mjs`). No dependencies, no `node_modules`.
- `npm run sim` — `python3 -m http.server 4801 --directory sim`. Must be HTTP (ES modules).

## Rules

- `materials.js`, `physics.js`, `sensors.js`, `detector.js`, `persona.js`, `voicecore.js`, `packs.js`
  are pure: no DOM, no three.js. Keep them that way; the tests and the planned C++ port depend on it.
- `detector.js` may read only the sensor frame. `frame.truth` exists for the telemetry plot only.
- `voicecore.js` is fetched as text, stripped of `export`, and registered inside an AudioWorklet.
  It must not import anything.
- `sim/vendor/three.module.js` is three.js r170, copied from `~/projects/experimental/smoke-spot-fps/vendor/`.

## Traps

- The desktop app's Browser pane throttles `requestAnimationFrame` to ~2 fps while hidden, so the sim
  crawls. Show the pane, or drive it from the console: `bloop.step(n)` runs n 10 ms frames.
- `sed -i` on this machine behaved as BSD sed in this repo's shell (`sed -i '' ...`); python edits are safer.
- After editing a module, the pane may serve a cached copy; `fetch(url, {cache: 'reload'})` then reload.
- The hand's catch must stay under ~2 g, or the detector reads a catch as an impact.
- The hand is two models: a grip (spring + push) while it holds, tosses, throws or catches its own
  ball, and a moving palm box that every other ball collides with. The arm is drawn only: a
  two-joint solve in `main.js` (`poseArm`), not part of the physics.
- Contact damping must stay capped (`dampCap`, `coreK` in `contactForce`). Uncapped, a light soft
  ball hitting hard gains energy at 4 kHz and leaves at hundreds of m/s. The stability test covers it.
- One sound at a time per ball is enforced in `voicecore.js` (`say`: interrupt replaces, polite is
  dropped when a line is playing) and mirrored for recordings in `BallVoice.playBuffer`. The
  "Saying now" panel reads `voice.now`, which the worklet reports, so captions match the audio.
- Room echo is off by default (`l-echo`). In the stairwell the reverberant sound is ~10 dB above
  the direct sound and rings 2.3 s, which turns one voice into a crowd. Loudness numbers still
  include the reverberant field either way.
- Voice styles live in `voicecore.js` `STYLE`: `human` (default: hum-weighted murmur, half-open
  mouth, low-passed buzz, wide formants) and `spirit` (the original "11th dimension" voice). Nobody
  can hear in tests: `brightness` (first-difference energy / energy) is the objective warmth proxy.
- "Hear the voice without the ball" (`audio.raw`) flattens the speaker and shell filters only;
  distance, panning and echo still apply.
- The default voice is recorded clips (`clipvoice.js` decides, `BallVoice.runClip` plays). The
  formant synth (`voicecore.js`) is only the "11th dimension" style; its "human" style was tried and
  rejected on 2026-10-18 ("a creature learning how to speak"). Don't re-propose tuning the synth as
  the toy's voice.
- `sim/packs/` is generated by `node scripts/make-pack.mjs` (macOS `say` + `afconvert` + ffmpeg).
  Samantha won't hold a long vowel at any speech rate, so screams are short clips repeated.
